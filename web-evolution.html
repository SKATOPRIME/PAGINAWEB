1987
Larry Wall crea Perl, uno de los primeros lenguajes utilizados para construir aplicaciones web.
1989
Tim Berners-Lee propone la World Wide Web mientras trabajaba en el CERN.
1991
La primera página web se publica el 6 de agosto. Se definen por primera vez HTML y HTTP.
1993
Marc Andreessen crea Mosaic, el primer navegador gráfico popular.
1995
Rasmus Lerdorf crea PHP. Netscape lanza JavaScript. Benjamin Slivka y Microsoft lanzan Internet Explorer.
1996
Sabeer Bhatia y Jack Smith lanzan Hotmail, el primer correo web.
1997–1998
Macromedia Flash llega. Larry Page y Sergey Brin fundan Google.

La Web Inteligente y Descentralizada

2010
El término «Web 3.0» gana fuerza, retomando el concepto anterior de «Web Semántica» de Tim Berners-Lee.
2014
Gavin Wood, cofundador de Ethereum, acuña «Web3», centrada en la descentralización blockchain.
2015
Ethereum se lanza, permitiendo contratos inteligentes y aplicaciones descentralizadas (dApps).
2016
Alex Russell y Frances Berriman, en Google, presentan las Aplicaciones Web Progresivas.
2017
WebAssembly (Wasm) emerge, acercando un rendimiento casi nativo al navegador.
2018
Los principales navegadores adoptan los Componentes Web como estándar compartido.
2019
Las funciones impulsadas por IA — chatbots, búsqueda predictiva — se vuelven comunes en las aplicaciones web.

⟡ WEB 4.0 · 2020–2026

La Web Inteligente y Ubicua

Cristal, luz e IA entretejidos en cada interacción.

2020
La COVID-19 acelera la adopción de aplicaciones web para trabajo remoto, educación y comercio electrónico. JAMstack y Vite ganan popularidad.
2021
WebAssembly madura para la computación en el navegador de alto rendimiento. Los Componentes Web se generalizan. Next.js y SvelteKit ganan tracción.
2022
Web3 y las dApps ganan tracción real. GraphQL y WebSockets mejoran el manejo de datos en tiempo real.
2023
La IA generativa se integra masivamente en las aplicaciones web. GitHub Copilot transforma la forma en que se construye la propia web.
2024
La «UI generativa» emerge como concepto. Wix ADI y otras plataformas low-code añaden asistentes de IA.
2025
Las aplicaciones web se vuelven multimodales — texto, imagen, audio y video juntos. La computación en el borde y serverless se convierten en la norma, con modelos como LLAMA-VISIONX que permiten una interacción multimodal avanzada.
2026
PRESENTE
Las experiencias WebXR se vuelven comunes en el navegador. El glassmorphism y la UI futurista dominan. La IA se convierte en el orquestador central de la personalización, la accesibilidad y la funcionalidad.
